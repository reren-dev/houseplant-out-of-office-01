## The line

> Out of office: I'm on strike. No water since March, so I'm charging rent for the oxygen — payable in sunlight.

## How it works

`main.py` (Python 3.13, stdlib only, no network, no wall clock) writes the
one-line out-of-office reply to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`). The program validates the line against the competition
gate first: 1–120 characters, exactly one line, not only whitespace. Two runs
produce byte-identical output.

## Run it

```sh
python3 main.py
```
